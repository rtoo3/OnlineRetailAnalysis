# Online Retail II Data Analysis in R

## Overview

This project analyses the Online Retail II transactional dataset using Base R. The project focuses on data quality assessment, data cleaning, transaction analysis, cancellations, missing values, duplicate records, and exploratory analysis of retail transaction data.

## Objectives

- Assess the quality of the raw transactional dataset
- Identify missing values and duplicate records
- Analyse cancellations and negative quantities
- Clean and prepare the transactional data for analysis
- Explore sales and transaction patterns
- Produce analysis outputs and visualisations

## Tools and Technologies

- R
- Base R
- Data Cleaning
- Exploratory Data Analysis
- Statistical Analysis
- Data Visualisation

## Dataset

This project uses the Online Retail II dataset.

The raw dataset is not included in this repository.
